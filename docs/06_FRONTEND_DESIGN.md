## 2. 학생 앱 (Flutter Native)

### 화면
- 로그인
- **기기 등록**: 최초 로그인 시 앱 생성 UUID를 계정에 바인딩(자동, 안내 표시)
- **기기 변경 재인증**: 학교 이메일(@wku.ac.kr) 인증 코드/링크 입력 화면
- 시간표 / 수업 목록
- 출석 인증 화면: QR 스캐너 + 마이크 음향 토큰 감지 상태 + **인증 창 남은 시간(카운트다운)**
- 내 출결 현황
- 위험군 경고 (인증 직후 / SSE 수신)
- 출결 문의 작성

### 음향 토큰 감지 UX
- 마이크 권한 요청(최초 사용 시 목적 고지 + 동의).
- 18~20kHz 대역 음향 토큰을 FFT/대역 필터로 복호하여 nonce 추출.
- QR 스캔 값 + 음향 nonce + **기기 UUID**를 함께 `POST /attendance/verify`로 전송.
- 감지 실패 시 재시도 안내. 실패가 곧 결석이 아님을 안내(교수 확인·창 연장 폴백).

### 기기 UUID 바인딩 (보안 저장)
- 최초 실행 시 랜덤 UUID 생성 → `flutter_secure_storage`/`flutter_udid`로 iOS 키체인/Android 키스토어에 저장.
- 이후 인증 요청에 이 UUID를 포함. 서버 응답이 `device_mismatch`면 이메일 재인증 화면으로 유도.
- **하드웨어 ID·`device_info_plus` OS 식별자는 사용하지 않음**(재설치·초기화 시 변동 → 오탐).

### 계정 전환 UX 넛지 (보안 아님)
- 인증 성공 후 계정 전환/로그아웃 시도 시 가벼운 확인 다이얼로그만 표시.
- **하드 로그아웃 쿨타임·세션 강제 잠금은 두지 않는다**(서버 유일성 규칙과 중복, 정상 사용자 오탐). 프론트엔드는 보안 경계가 아니라 UX로만 취급.

### 생체인증(선택)
- Face ID/지문 챌린지 서명은 향후 확장 옵션. 기본 플로우에는 포함하지 않음.

## 3. 교수 대시보드 (React Web)

### 화면
- 로그인
- 수업/시간표 설정
- 출석 진행 화면: **QR 코드 표시 + 스피커 음향 토큰 송출**(15초마다 갱신) + **1분 인증 창 시작/연장/종료 버튼**
- 실시간 출석 현황(SSE): 출석률, 미인증자 목록
- Opt-out 정정: 결석자만 수동 처리, 변경분(Delta)만 Batch UPDATE 전송
- 출결 문의 확인/답변

### 상태 관리 / 음향 송출
- Zustand로 미인증자/정정 대상 상태 관리. 마감 시 변경된 레코드(Delta)만 추출 전송.
- 교수 PC 스피커로 nonce를 실은 준-초음파 신호 방출(별도 하드웨어 불필요).

## 4. 실시간

- SSE로 위험군 경고(학생) 및 실시간 출석 현황(교수) 수신. WebSocket 상시 연결은 사용하지 않음.

## 5. 접근성 / UX 원칙

- 처음 사용해도 이해 가능한 간단한 메뉴.
- 음향/마이크 실패·1분 창 놓침 시 명확한 폴백 안내(교수 확인·창 연장)로 정당한 출석자가 사후 증명 부담을 지지 않도록 설계.
